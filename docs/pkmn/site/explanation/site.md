# The pkmn Site

The group's Pokémon web app, `pkmn/site/`, served at `pkmn.enbraile.vip`. It holds a home page listing the tools, [Open Sheet](open-sheet.md) at `/open-sheet` and [Team Analysis](team-analysis.md) at `/team-analysis`. More tools will join it over the series, and a backend on Vercel Functions may follow. Running and deploying it is in [How to Run and Deploy the Site](../how-to/run-and-deploy-the-site.md). It was scoped with the owner on 2026-10-15.

## Stack

npm; Vite 8, React 19, TypeScript 7, Tailwind 4 and shadcn/ui; TanStack Router; zod 4; Dexie over IndexedDB; `@pkmn/dex` and `@pkmn/img` for Showdown's data and sprites. Every package is pinned exactly, at its latest stable version when it went in (the scaffold, 2026-10-16: vite 8.3.4, react 19.3.1, typescript 7.0.2, tailwindcss 4.3.3, shadcn 4.21.5, @tanstack/react-router 1.170.44, @pkmn/dex 0.10.11, @pkmn/img 0.3.4). The gate is `npm run gate`: `tsc -b`.

Routes are declared in code in `src/router.tsx`, not with TanStack Router's file-based plugin: a handful of routes needs no generated route tree for `tsc` to check before a build. A tool gets its route there and its home-page card from `src/tools.ts`.

## Look

The [Open Sheet Screens](https://claude.ai/artifact/SfpFcW5UoLVLeLAmdJZMG1) design in Claude Design, signed off by the owner on 2026-10-16, set the look: one dark theme, charcoal with a slate-blue PC and orange for actions, and no light theme. No helper text explaining the UI. The UI is in English, since Showdown's names are. Desktop-first, with every view usable on a phone.

That look is now the site's design system, kept in the repository: the code (`src/index.css`'s tokens, the shell, the shared components) is its source of truth, and the [Site Design System](../reference/design-system.md) describes it, changing in the same commit as the code does. A new page follows [How to Add a Page to the Site](../how-to/add-a-page-to-the-site.md).

shadcn was initialised with its Nova preset on Radix, its palette replaced by the design's colours as the only theme, and its vendored components in `src/components/ui/` follow the same token rule. The design's fonts are bundled from Fontsource rather than loaded from Google Fonts, and the type icons come from duiker101's [Pokémon Type SVG Icons](https://github.com/duiker101/pokemon-type-svg-icons), free for any use, bundled in `src/lib/type-icons.ts`, so the only runtime calls the site makes are for Showdown's sprites.

The tab icon is a spiral notepad with a red and white Poké Ball drawn on it and a pencil writing on it: `public/favicon.svg`, plus `favicon-32.png` and `apple-touch-icon.png` rendered from it for browsers that take no SVG icon.

## Data and Storage

Everything a reader imports or builds stays in their browser, per browser and device: Open Sheet's in IndexedDB, Team Analysis's drafts in `localStorage`. Nothing goes to a server, and there are no accounts. Game data (names, descriptions, base stats, the type chart) is bundled from `@pkmn/dex`; no API is called at runtime. Sprites load from Showdown's sprite server, `play.pokemonshowdown.com`, through `@pkmn/img`'s URLs.

## Hosting and Deploys

Vercel serves the site from the owner's Hobby account: the Vite build's static `dist/`, with `pkmn/site/vercel.json` rewriting every path to `/index.html` so deep links load the single-page app. It is static only for now, and a backend would be Vercel Functions in the same project. `pkmn.enbraile.vip` is a DNS-only (grey-cloud) `CNAME` to the Vercel target in the `enbraile.vip` zone, which stays on the owner's Cloudflare account. If the record were proxied, traffic would go through Cloudflare's IPs again, which Spanish ISPs block during LaLiga matches.

Vercel's Git integration, connected to the GitHub repository in the Vercel dashboard with root directory `pkmn/site`, builds and deploys each push to `main` that touches `pkmn/site/`. Pushes that touch nothing there are skipped, and each branch push gets a public preview URL (Vercel Authentication is off for previews). A preview or `vercel.app` URL is a different origin from `pkmn.enbraile.vip`, so its IndexedDB and `localStorage` start empty. There are no secrets in the repository. A bad deploy is undone with Vercel's Instant Rollback to the previous production deployment, or by reverting the commit, which redeploys.

The site logs nothing of its own: Vercel's build and deployment logs cover the deploy, there is no Web Analytics, and import errors are shown to the reader.

## Decisions

- **Legends are keys, not explanations.** Team Analysis's compare and pool legends were cut to their keys ("weak / resist · shaded: no switch-in", "super-effective · shaded: none", "shaded: percentile · L legendary · M mythical"), and [Design System](../reference/design-system.md)'s "No helper text" rule names legends as keys only. **Why:** the owner; the keys are needed to read the cells, the prose on how they are computed is helper text. _(owner, 2026-10-22)_
- **No tests; the gate is `tsc -b` alone.** The site's vitest suite and vitest itself were removed. **Why:** the owner's rule for every project, in the root `CLAUDE.md`. _(owner, 2026-10-20)_
- **One site for the group's Pokémon tools,** `pkmn/site/`, starting with Open Sheet at `/open-sheet` beside a home page listing the tools; its docs in `docs/pkmn/site/`. **Why:** the site will grow in depth over the series. _(owner, 2026-10-15)_
- **Vite, React, TypeScript, Tailwind and shadcn at their latest versions, pinned exactly;** TanStack Router, zod, Dexie, `@pkmn/dex` and `@pkmn/img` alongside. **Why:** the owner chose the core stack to future-proof the site; the rest follows the owner's unlit and blink sites (`~/workspace/unlit/apps/web/`, `~/workspace/blink/`), confirmed by the owner. _(owner, 2026-10-15)_
- **Routes in code, shadcn's Nova preset on Radix with the design's palette, Fontsource fonts, static assets with SPA fallback:** build choices made while scaffolding. **Why:** no generated route tree to check, and no runtime calls beyond sprites. _(settled 2026-10-16)_
- **The vendored shadcn components follow the theme rule,** with the dialog scrim as a `--scrim` variable. **Why:** delegated by the owner during an unattended run; the scaffold already replaced shadcn's palette and the design draws that scrim. _(settled 2026-10-16)_
- **The Open Sheet Screens design, dark only, no explanatory labels, English, desktop-first.** _(owner, 2026-10-16)_
- **The design system lives in the repository, with the code as its source of truth and one owning doc describing it,** the [Site Design System](../reference/design-system.md); any change to tokens, shared components, the layout shell or patterns updates that doc in the same change, and new UI uses what exists first. The Claude Design canvas stays the record of the original sign-off, not the live system. **Why:** the owner asked for a design system that is used and improved as the site grows, and that any agent reading the repository can follow and change. _(settled 2026-10-21)_
- **One shared version of each UI piece:** what more than one tool shows lives in `src/components/` (the controls, the type marks, the analysis panels in `src/components/analysis/`), and no tool imports another tool's components; Open Sheet's own `Panel` and PC/Team switch gave way to the shared `Panel` and `Segmented`. The Open Sheet → Team Analysis handoff (`carryTeam` in `src/team-analysis/drafts.ts`) stays a direct import, since it writes Team Analysis's own drafts rather than drawing UI. _(settled 2026-10-21)_
- **One button:** the vendored shadcn `Button` was resized to the site's buttons (`min-h-10`, `rounded-lg`, `text-sm`, semibold; `size-10` and `size-7` icon sizes), and the hand-built buttons take its classes through `primaryClass`, `buttonClass`, `iconButtonClass` and `quietIconClass`, so every button has one size and one style. Primary actions lost their `min-h-11`. _(settled 2026-10-21)_
- **Tailwind's scales only for type and radius:** radii are `rounded-lg` (10px), never `rounded-[10px]`; 14px → `rounded-xl`, 20px → `rounded-2xl`, 7px → `rounded-md`, 5px and bare `rounded` → `rounded-sm`. Text 10px and 11px → `text-xs`, 13px → `text-sm`, 17px → `text-lg`, 22px and 26px → `text-2xl`, 30px → `text-3xl`, 34px → `text-4xl`. **Why:** the nearest step on the scale keeps the look while leaving one spelling per size. _(settled 2026-10-21)_
- **One gutter and one width per page kind:** every page is a centred column with the header's `px-4 sm:px-8` (`src/components/page.ts`), `max-w-240` for a list page (home), `max-w-344` for a tool (Open Sheet as well as Team Analysis, so Open Sheet is no longer full width) and `max-w-180` for a message. _(settled 2026-10-21)_
- **Duplicate colour tokens are aliases:** `chart-1` is `var(--primary)`, `chart-4` `var(--destructive)`, `secondary` `var(--cell)`, and likewise `popover`, `input`, `ring` and the `*-foreground` copies of `foreground`, each kept for its own role; the unused `chart-5` and `sidebar-*` tokens were dropped. _(settled 2026-10-21)_
- **A hub per series, agreed in direction:** the home page lists the series, each series has a hub at `/series/<n>`, and Open Sheet and Team Analysis sit under it. What a hub shows will be scoped as its own piece of work, after Añil's tooling: "nothing now, we will build this next". _(owner, 2026-10-21)_
- **Nothing is stored server-side:** imports, teams and drafts live in the reader's browser. _(owner, 2026-10-15; Team Analysis's drafts since 2026-10-17)_
- **Vercel at `pkmn.enbraile.vip`, deployed by Vercel's Git integration** on pushes to `main` touching `pkmn/site/`, with public branch previews, and DNS staying on Cloudflare as a DNS-only record. **Why:** Spanish ISPs block Cloudflare's IPs during LaLiga matches, taking the site down. Vercel was blocked once, in April 2025, and unblocked within days. The owner accepted that remaining risk to keep managed deploys rather than run a VPS. _(owner, 2026-10-20; replaces Cloudflare Workers, chosen 2026-10-15)_ Seen working on 2026-10-20: `pkmn.enbraile.vip` resolved to Vercel and returned `server: Vercel` with a Let's Encrypt certificate.
- **Vercel's Git integration rather than a GitHub Action with the Vercel CLI; previews public; no Vercel Web Analytics.** **Why:** the Git integration works like the old Workers Builds and keeps tokens out of GitHub, public previews let friends open them without a Vercel account, and without analytics the only runtime calls the site makes are for sprites. _(owner, 2026-10-20)_
