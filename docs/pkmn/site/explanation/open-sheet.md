# Open Sheet

Series 1's final tournament is played open sheet ([Series 1 Rules → Final Tournament](../../series/1/reference/rules.md#final-tournament), since 2026-10-22), and before that two players could agree to an open-sheet fight instead of a closed-sheet one: each shares their Pokémon with the other, with their stats, IVs and EVs, along with their abilities and the bag items that matter in a fight (held items, berries and TMs), and each builds their team from there (the owner's brief, 2026-10-15; stats, IVs and EVs shared since 2026-10-21). Open Sheet is the tool for that, in two parts: an export a player ran on their save, which wrote a JSON file (a Python script, retired on 2026-10-23 for the site's [Save Export](save-export.md)), and this web app, a route of [the pkmn site](site.md) at `/open-sheet`, which reads those files and helps the reader understand them and build teams from them. It was scoped with the owner on 2026-10-15.

The reader imports exports, each into its own tab, and on every tab looks through the sheet in a PC, searches it and filters it by type, builds named teams from it in that same PC, and analyses a team on a team page, following pokeos's builder: stats, what is effective and what is not. A team leaves the site as Showdown text and comes back in the same way. The site has no notion of "my sheet" or "the rival's sheet": any number of exports can be imported, and every feature works on every tab.

It is done when, deployed at `pkmn.enbraile.vip`, a reader drops in two exports, gets two tabs, browses each with sprites, Showdown base stats, abilities, items and TMs, builds a named team in either tab, sees its stats, defensive chart and offensive coverage, and copies it as Showdown text; closing and reopening the browser keeps the tabs and teams.

**Out for now:** a matchup of a team against another tab's Pokémon (the team page analyses the team alone), a damage calculator, shareable links, accounts and server-side storage, a Spanish UI, and TM compatibility beyond what an export with moves carries. Comparing teams and the damage calc have since gone to the Team Analysis tool, which an Open Sheet team reaches through its "Open in Team Analysis" button ([Team Analysis](team-analysis.md)).

## What It Reads

The JSON the retired Python export wrote, exactly as the first three keys of the [Snapshot Format](../reference/snapshot.md) define it. Which items go out is decided in [Save Export](save-export.md#decisions). Moves and learnsets were not in the script's default export, but the views and the stored model leave room for them: a member already has four move slots, and the learnable moves an export with moves carries narrow the move picker instead of reshaping the builder.

Names, descriptions, base stats and the type chart come from `@pkmn/dex`, Showdown's data, Gen 9. Fights are Showdown "[Gen 9] Custom Game" ([Series 1 Rules → The League](../../series/1/reference/rules.md#the-league)), and several Gen 1–5 Pokémon gained base stats in Gen 6+, so Showdown's Gen 9 data is what the fight runs; PokéAPI's cartridge data is not, and the export's IDs already follow Showdown.

Showdown's types and base stats drive the analysis, since Showdown sets a species' types from its own data whatever the save says. A card shows the export's `types` and flags a species whose export types differ from Showdown's; the mod's types are modern (Clefairy is `FAIRY` in the mod's `types.txt`), so a mismatch should be rare. An ID `@pkmn/dex` does not know is shown by its raw ID with a marker and kept out of the analysis; `tinymushroom` is the one expected case and gets a hand-kept label, "Mini Seta (Tiny Mushroom)", without the marker.

Sprites are Showdown's Gen 5 static set, which fits the Gen 1–5 roster, shiny and female where they apply, with a "?" in place of an unknown species'; item icons come from `@pkmn/img` too.

## Importing and Storage

A file is dropped onto the page or chosen with a file picker, read in the browser and validated by `sheetSchema` in `shared/snapshot.ts`, the zod schema that mirrors the JSON reference, which `src/open-sheet/schema.ts` re-exports and checks imports with; it ignores keys it does not know, so a field added to the export does not mark old imports. In a Pokémon every key but `species` reads as absent when it is missing or not of its type, as for an old export uploaded to the site ([Snapshot Format → Old Exports](../reference/snapshot.md#old-exports)). A file that fails is refused above whatever view is open, naming the first failing field by its JSON path after the file name: "MIRAMEEE-open-sheet.json has no pokemon list", "… has no pokemon[0].species". Each import opens a new tab named after the file (`MIRAMEEE-open-sheet.json` → `MIRAMEEE`), renamable. Nothing is uploaded.

The Dexie database `open-sheet` holds an `imports` table (file name, import time, the validated JSON) and a `tabs` table (name, position, its import) since version 1, and a `teams` table since version 2. Each tab has its own import; closing a tab deletes it with its teams. The tab last opened, picked or imported is remembered in `localStorage` (`open-sheet:tab`) and reopened on the next visit, falling back to the first tab when it is gone.

The JSON has no format version, so the site checks shape, not version. Every stored import is checked against the schema when the tabs load; a failing one marks its tab and opens it as the import view with the reason and a prompt to import the file again, and a file dropped anywhere on that tab replaces its import instead of opening a new tab, keeping the tab's name and teams. A stored import is never silently dropped. Dexie's schema versions migrate the stored model when its shape changes.

## The PC

The PC is the tab's main view: its Pokémon in a scrollable box grid, searchable by name and filterable by type, under a strip of six team slots. Its box, summary and bag are the pieces the site's PC page shows a stored snapshot with ([The pkmn Site → Snapshots](site.md#snapshots)). Each Pokémon, item and TM is looked up by `src/open-sheet/dex.ts`. The type filter uses Showdown's types, and the export's for a species Showdown does not know.

Clicking a Pokémon opens its summary: Info, with its nature, every possible ability and its description, and its type defenses; Stats; and Moves, listing its current moves before the relearner moves and TMs, or "No moves in this export". A Pokémon's possible abilities are the export's `abilities` (the randomizer's), not Showdown's for the species, since the randomizer rerolls them; a current ability missing from them is listed first. Stats lists each stat's Showdown base, the export's IV and EV, and the export's stats at the Pokémon's own level; its Lv 50 view shows its fight stats instead, worked out from its IVs and nature with 1 EV in every stat (which adds nothing at Level 50), as in the league's Showdown fights. A Pokémon without IVs shows its Level 50 range, IVs 0–31, there instead, and opens on it. A species with a fixed `maxHP` in Showdown's data shows that HP at any IV: Shedinja's is 1. The summary is docked beside the PC from 1024 px wide and is a bottom sheet below that.

The Bag button opens a scrollable bag, a dialog or a bottom sheet on a phone, with Items, Berries and TMs pockets. The export carries no pocket, so items go to Berries when Showdown marks them as berries and to Items otherwise, unknown IDs and `tinymushroom` included.

## Building Teams

A team is built in the PC by pointing and clicking, with no drag and drop, as in a real Pokémon PC. The summary's button adds the Pokémon to the first free slot or removes it; it reads "Team full" and is disabled when the six slots are taken, and on a phone adding or removing closes the bottom sheet. A slot of the strip opens its Pokémon's summary. Clicking a bag entry shows the team's members, and clicking one gives it the item or teaches it the TM. The PC and Team views are switched in the toolbar beside the team picker.

Each tab holds any number of named teams, which can be created, renamed, duplicated, deleted (after a confirmation) and imported from Showdown text. A tab always has at least one team: its first is made as "Team 1" when the tab opens with none, and deleting the last makes a new one; a new or imported team takes the lowest free "Team n", and a duplicate is named "<name> copy".

Each team is a row of the `teams` table (its tab, name, six slots). A member holds the Pokémon's index in the export and its species, its item, its picked ability (none while it keeps its current one) and four move IDs. A member whose index no longer holds that species after its import is replaced is treated as an empty slot holding no item, and is dropped on the next save. The PC writes the whole row on every change, keeping the latest slots in memory until its writes have landed, so an edit made before the previous write comes back is computed from the edited team, not the stored one; a quick second edit used to undo the first, seen as an ability changing back.

**Items.** A member can hold an item only while the tab's `quantity` of it is not used up; once it is, the item shows as unavailable. Only items Showdown knows can be given, so not `tinymushroom`. A held item can be taken back in the Team view, and clicking a member's item slot there opens the bag for that member with only its Items and Berries pockets, since a TM is not an item to hold.

**Abilities.** A member uses its current ability by default, switchable to any of its `abilities`, base or hidden, marked as not its current one. In the game an NPC switches an ability for one Mini Seta, to any of the Pokémon's abilities, hidden included; so the team shows how many Mini Setas the build needs, one for each member whose picked ability is not its current one, against the tab's `tinymushroom` quantity.

**Moves.** Teaching a TM fills the first empty move slot, or the fourth when all are full, and does nothing if the member knows it; picking a move a member already has in another slot moves it there. The move picker is a searchable dialog, as wide as the bag, whose rows show each move's type, category, power, accuracy and Showdown short description. Without learnable moves it lists the tab's TMs first (any TM on any member, since compatibility is unknown), then every move Showdown gives generations 1–5 (Hidden Power once, without its typed copies or Struggle). When the export carries the Pokémon's learnable moves, the picker lists only those, in three groups: Current moves (the four it knows in the save, which may include a move kept from a previous evolution that no other list has), Move Relearner and TMs, with no "All moves". A Pokémon added to a team starts with its current moves in its slots, in the save's order. The bag's TMs pocket keeps teaching TMs, greying out members that cannot learn one ("Can't learn"), and a member holding a move it cannot learn (picked before such an export was imported, or pasted in) shows that slot in the warning colour with a line naming the moves. This is designed in the Open Sheet Screens canvas's "Learnable moves" row.

## The Team Page

The Team view shows each member's item, ability, four moves and Level 50 stats, with the analysis below:

- **Stats:** each member's base stats and Level 50 stats from its IVs, and the team's speed order by its Level 50 Speed. They are exact for the league's pokepastes: Level 50, real IVs, 1 EV in every stat ([Series 1 Rules → Pokepastes](../../series/1/reference/rules.md#pokepastes)). A member without IVs shows its Level 50 range instead and sorts by its IV 31 speed, then its IV 0 speed.
- **Defensive chart:** for each of the 18 types, how many members are weak (above ×1), resist (below ×1) or are immune (×0), using Showdown's Gen 9 type chart over each member's Showdown types and its picked ability (its current one when none is picked). A type is a hole when more members are weak to it than resist or are immune to it.
- **Offensive coverage:** which types the picked moves hit super-effectively on their own, and which types nothing covers.

Since 2026-10-17 these three panels sit in the Summary of an Analysis section that adds Team Analysis's archetype, checklist, graph, member cards and matrices, and an "Open in Team Analysis" button carries the team there through its Showdown text ([Team Analysis → Teams In and Out](team-analysis.md#teams-in-and-out)).

Members with an unknown species are left out. The abilities that change a matchup come from the site's one matchup-ability table ([Team Analysis → Data](team-analysis.md#data)), read in Gen 9 like the type chart. Its later entries never occur here, since an export only holds the Gen 1–5 abilities the mod rolls. Filter and Solid Rock only trim super-effective damage and change no matchup.

Coverage counts a member's damaging picked moves, leaving out status moves, fixed-damage moves (Seismic Toss, Sonic Boom…), one-hit KOs, moves whose damage ignores type matchups (Counter, Mirror Coat, Metal Burst, Bide, Final Gambit, Psywave, Super Fang, Endeavor) and Hidden Power, whose type depends on IVs the export does not hold. A member with no damaging move picked stands in with its STAB types.

## Showdown Text

**Copy.** The "Copy for Showdown" button, in the Team view's header beside the Mini Seta count, writes the team with `src/open-sheet/showdown.ts` in the layout of Showdown's own export: `Nickname (Species) (M) @ Item`, with the nickname only when it differs from Showdown's species name, the export's gender whenever it is `M` or `F` (Showdown's export leaves it out for a species of fixed gender; its importer accepts it), and the item only when one is held; then `Ability:` (the picked one, else the current one, left out when the export has none), `Level: 50`, `Shiny: Yes` when shiny, the league's `EVs: 1 HP / 1 Atk / 1 Def / 1 SpA / 1 SpD / 1 Spe`, `<Nature> Nature` when the export has one, `IVs:` with each IV below 31, as Showdown's own export lists them, and one `- Move` line per filled move slot. Level 50, real IVs and 1 EV in every stat are the league's format ([Series 1 Rules → Pokepastes](../../series/1/reference/rules.md#pokepastes)). Names are Showdown's, and an ID it does not know is written as is. Members are separated by a blank line; empty slots, members whose index no longer holds their species and species Showdown does not know are left out, since Showdown's importer could not place them. The button is disabled when nothing would be copied, and reads "Copied", or "Copy failed" when the browser refuses the clipboard, for a moment after a click.

**Import.** The toolbar's "Import from Showdown" button opens a dialog to paste a team in Showdown's format, which the site's shared Showdown parser (`src/analysis/paste.ts`) reads and `src/open-sheet/showdown.ts` turns into a new team of the tab; the view then switches to it. Each set is matched to a Pokémon of the sheet by its species, preferring one whose nickname matches and skipping those already placed, so a sheet with two of a species can field both. Its item is given when the tab still has one left, its ability is picked when it is one of the Pokémon's `abilities`, and its moves fill the four slots whether or not the Pokémon can learn them, so the usual warning shows on a move it cannot learn; a typed Hidden Power reads as Hidden Power. Gender, shiny, nature, level, EVs and IVs are ignored, since the sheet holds those; `===` team headers, a move's `/` alternatives after the first and any set past the sixth are skipped. Whatever the sheet cannot back is left out and listed in the dialog with its reason: a species not in the sheet or with every copy already placed, an item none of is left or Showdown does not know, an ability the Pokémon cannot have, a move Showdown does not know. When nothing matches, no team is made.

## Decisions

- **The tool imports exports into tabs, browses them in a PC, builds teams there and analyses them on a team page.** **Why:** the owner chose the browse, filter, two-sheet and team-builder jobs; the team page follows pokeos's builder. _(owner, 2026-10-15)_
- **No notion of whose sheet is whose;** any number of imports, every feature on every tab. **Why:** the reader does whatever they want with each import. _(owner, 2026-10-15)_
- **Team-only analysis and no damage calculator, for now;** no shareable links, accounts, server storage or Spanish UI. _(owner, 2026-10-15)_
- **The views and model leave room for moves and learnsets** the default export does not carry. _(owner, 2026-10-15; stats carried since 2026-10-21)_
- **The site reads the export's JSON as its reference defines it,** dropped or picked, validated in the browser, refused with what was wrong, one tab per import named after the file. _(owner, 2026-10-15)_
- **`@pkmn/dex`'s Gen 9 data, bundled, for names, stats and the type chart; Showdown's sprite server through `@pkmn/img` for sprites.** **Why:** the owner asked for a good source of base stats and sprites; Showdown's Gen 9 data is what the fight runs. _(owner, 2026-10-15)_
- **Showdown's types drive the analysis,** with a flag on an export-type mismatch. **Why:** forced by where the fight runs. _(settled 2026-10-15)_
- **An unknown ID is shown raw with a marker and kept out of the analysis;** `tinymushroom` gets a hand-kept label. _(settled 2026-10-15)_
- **Point-and-click PC with a bag and many named teams per tab.** **Why:** the owner, in the design pass: a real Pokémon PC with a bag, no drag and drop. _(owner, 2026-10-16)_
- **Item quantities limit a team.** _(owner, 2026-10-15)_
- **Any of a member's `abilities` can be picked, counted against the tab's Mini Setas.** **Why:** an NPC switches an ability for one Mini Seta, to any of the Pokémon's abilities. _(owner, 2026-10-15)_
- **Move slots take the tab's TMs then any Gen 1–5 move; for an export with moves, one picker of relearner moves and TMs, the bag still teaching TMs, and a warning on a move the member cannot learn.** _(owner, 2026-10-15 and 2026-10-16; unchecked TMs dropped 2026-10-21, once the export rolls them)_
- **For an export with moves, a Pokémon's current moves count as learnable, are listed first, and fill a new team member's slots.** **Why:** a move kept from a previous evolution is in no other list, and the team should start from what the Pokémon actually knows. _(owner, 2026-10-17)_
- **A member's item slot opens the bag with only Items and Berries.** **Why:** a TM is not an item to hold. _(owner, 2026-10-17)_
- **The move picker is as wide as the bag and describes each move.** _(owner, 2026-10-17)_
- **The team page shows Level 50 stats, a defensive chart and offensive coverage.** **Why:** the owner's choice; with the export's IVs they are exact for the league's pokepastes. _(owner, 2026-10-15; exact from IVs 2026-10-21)_
- **The summary keeps Showdown's base stats and shows the export's IVs, EVs and current stats, with a checkbox for the Level 50 fight stats.** **Why:** the owner's choice once the export carries them. _(owner, 2026-10-21)_
- **The team page's three panels sit in the Summary of a deeper Analysis section, with an "Open in Team Analysis" button; comparing and the damage calc live in Team Analysis.** _(owner, 2026-10-17; see [Team Analysis](team-analysis.md))_
- **The analysis rules** (the weak, resist, immune and hole thresholds, the speed order, the moves coverage leaves out, STAB stand-ins): build choices made while building the team page; the matchup abilities, first a hand-kept Gen 3–5 list, come from the site's shared table since 2026-10-17 ([Team Analysis → Data](team-analysis.md#data)). _(settled 2026-10-16; shared table 2026-10-17)_
- **Imports, tabs and teams in the Dexie database `open-sheet`;** stored imports checked on load, a failing tab marked and replaced in place, refusals naming the first failing field. **Why:** build choices made while implementing importing; replacing in place keeps a marked tab's name and teams. _(settled 2026-10-16)_
- **The last opened tab is remembered in `localStorage` and reopened.** _(owner, 2026-10-17)_
- **The PC reads the export's abilities, pockets by Showdown's berry flag, Gen 5 sprites, Level 50 stats with 1 EV, Shedinja's fixed HP, a docked summary from 1024 px:** build choices made while implementing the PC. **Why:** the export carries no pocket and the randomizer rerolls abilities. _(settled 2026-10-16)_
- **Team storage and editing rules** (whole-row writes from the latest slots in memory, stale members dropped, "Team n" and "<name> copy" names, at least one team per tab, TM teaching into the first empty or fourth slot, Hidden Power once in the picker): build choices following the Open Sheet Screens design; writing from memory fixed lost quick edits. _(settled 2026-10-16 and 2026-10-17)_
- **A team copies as Showdown text in Showdown's export layout,** Level 50, with its real IVs. **Why:** the owner; Level 50 and real IVs are the league's format, and the layout follows Showdown's own export. _(owner, 2026-10-15; layout settled 2026-10-16; IVs since the export carries them, 2026-10-21)_
- **The copy writes the league's 1 EV in every stat.** **Why:** the owner: it is the league's paste format and reveals nothing. Replaces the earlier "no IVs or EVs". _(owner, 2026-10-17)_
- **A team can be imported from Showdown text into a new team,** matched to the sheet by species and nickname, keeping only what the sheet backs and listing the rest. **Why:** the owner asked for it, so a team built in Showdown's teambuilder can be checked against the sheet's stock; making a new team rather than overwriting one, the matching and the left-out rules are build choices. _(owner, 2026-10-17; rules settled 2026-10-17)_
