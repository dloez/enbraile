# Series 1 Dictionary

| Term | Definition | Also Known As |
|------|-----------|---------------|
| Nuzlocke | Self-imposed challenge ruleset for Pokémon games; its core rule is that a fainted Pokémon counts as dead and can't be used again | Locke |
| Randomlocke | Nuzlocke played on a randomized game. The format series 1 uses | |
| Seed | The randomizer seed a player uses. Everyone shares the base game and settings but has a different seed | |
| Level Cap | The maximum level allowed before a given gym | Per-gym level cap |
| Dead Pokémon | A Pokémon that fainted during the run. Can't be used in the story or in PvP | |
| Lives | Extra chances after a wipe or death. Series 1 has none | |
| League Round | One round of 1v1 best-of-three matches between two of the 6 players, one per gym, played on Pokémon Showdown; a win gives 1 point | Jornada de liga |
| League Points | Points from league wins (1 per win); they rank players and seed the final tournament | |
| Pokepaste | A player's team, exported from the game's pause menu right after beating a gym or the League (posting it to pokepast.es is optional); frozen for that round's matches | |
| Egg | One of the 16 eggs the mod gives every new game, opened by a league match win; the extra catch | Huevo, captura extra |
| Series | One playthrough of a game by the group under its own rulebook, identified by number; series 1 is Pokémon Añil ([Repository Layout → Games and Series](../../../../general/explanation/repository-layout.md#games-and-series)) | |
| Bo3 | Best of three games | |
| Final Tournament | End-of-series PvP among the players who finished the story without losing the challenge | |
| Team Preview | Pre-battle reveal of the opponent's team; shows species only | |
| Finisher | A player who completed the story without losing the challenge, qualifying for the final tournament | |
