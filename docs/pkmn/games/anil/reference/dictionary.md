# Game Dictionary

| Term | Definition | Also Known As |
|------|-----------|---------------|
| Pokémon Añil | The Spanish fan game series 1 is played on, v4.14 | Añil |
| Pokémon Essentials | The RPG Maker XP framework Pokémon Añil is built on (v21.1); its game logic is Ruby scripts and plugins | Essentials |
| RPG Maker XP | The engine Essentials runs on | RMXP |
| Fakemon | A fan-made species or form that is not in the official games | |
| Warp | A tile that moves the player to another map (doors, stairs, cave entrances) | |
| Connection | An edge between adjacent overworld maps walked across without a warp | |
| Montura Surf | The key item (`SURFITEM`) that lets the player surf from a shore by pressing C at the water, with no badge needed; its message calls it "Montura Surf" | Surf |
| Rock Climb | Crossing a cliff of Rock Climb tiles (terrain tag 18) by pressing C at it with the `ROCKCLIMBITEM` key item, which the game names Equipo de Escalada; the game then moves the player across and jumps off the far side. Pokémon Z's equivalent was the Gogoat climb, gated on the `BICYCLE` | Equipo de Escalada, Treparrocas |
| Learnset | The moves a species learns by level | |
| TM compatibility | Which TMs/HMs a species can learn | TM compat |
| Double battle | A battle with two active Pokémon per side | |
| Mechanics generation | The generation whose battle rules Essentials follows (`Settings::MECHANICS_GENERATION`); 9 in Añil, independent of which species and moves are in the game | |
| Frostbite | The Legends: Arceus status Añil inflicts in place of freeze; the Randomlocke mod turns it off and restores freeze ([Battle Mechanics → Statuses](battle-mechanics.md#statuses)). The game names both "Congelado" | Congelado |
| Shiny | A Pokémon in its alternate colours; Añil's chance and sources are in [Shinies](shinies.md) | Variocolor |
| Super shiny | A shiny shown with square sparkles ([Shinies → The Shiny Roll](shinies.md#the-shiny-roll)) | |
| Catch chain | The Visible Overworld Wild Encounters add-on's count of the same species defeated or caught in a row, which raises its extra shiny chance ([Shinies → Raising the Chance](shinies.md#raising-the-chance)) | Cadena shiny |
| Shiny Potion | `SHINYZADOR`, the item that makes the next wild Pokémon shiny ([Shinies → The Shiny Potion](shinies.md#the-shiny-potion)) | Poción Brillante |
| Pokévial | The key item (`VIAL`) that heals the party outside battle from a limited number of charges, refilled by nurses ([League, Pokévial and Candy Cups → The Pokévial](league.md#the-pokévial)) | `VIAL`, `EMPTYVIAL` when empty |
| Candy cup | The cup in each Pokémon Center that gives 100 Rare Candies each time it is examined ([League, Pokévial and Candy Cups → Candy Cups](league.md#candy-cups)) | Taza |
