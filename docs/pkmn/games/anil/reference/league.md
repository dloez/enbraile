# League, Pokévial and Candy Cups

The Pokémon League's battle rules, healing and exits, the Pokévial, and the Rare Candy cups, as the game's code and data have them and as checked in game. What players do with them is in [Rules → Healing and Rare Candies](../../../series/1/reference/rules.md#healing-and-rare-candies) and [Rules → The Pokémon League](../../../series/1/reference/rules.md#the-pokémon-league). Its facts were verified with Wonder's harness and are kept as recorded there; [Runtime](runtime.md) maps Wonder's commands, modules and paths to `anil`'s.

The in-game rows were seen on 2026-10-02 on `es-v4.14` with the Randomlocke mod and the bridge, in session `20261002-194407` (save `league-1`), booted by `wonder run --hidden` into the snapshot `shop-new`, taken in the bedroom (map 28) of a new game in session `20261002-154150`, with no Pokémon and no badges. A throwaway driver script used the harness's own `transfer`, `go`, `interact` and battle-menu helpers (`packages/harness/src/harness/check.py`, `navigate.py`, `dialog.py`); the session records its result as a `wonder check` entry named `league`, though it is not one of the `wonder check` checks. The script set the party to a single level 75 Mewtwo by eval and added 3 Potions before Lorelei's battle. Its first run, before it walked to the cups, had its presses refused and is superseded. The other rows were read from the game's data on the same date: `rubymarshal` reads of `Data/MapInfos.rxdata`, `Data/CommonEvents.rxdata` and every `Data/Map*.rxdata`, and `PBS/trainers.txt` and `PBS/items.txt`. Code citations are to `S/` (the scripts) and `P/` (the plugins), as in [Runtime](runtime.md).

## The Pokévial

| Item | Value | How verified |
|------|-------|--------------|
| Item | `VIAL`, "Pokévial", a key item, price 0, field use Direct; when its charges run out the bag holds `EMPTYVIAL` instead (`S/419_Pokevial.rb`; `PBS/items.txt`) | Read from the scripts and PBS |
| How it is got | `give_vial` from Professor Oak's lab in Pueblo Paleta (map 29, event 19), free | Read from the map data |
| What it does | Used from the bag or the field, it shows the charges left, asks "¿Quieres curar a tu equipo?" ("Heal your team?"), and on yes runs `$player.heal_party` and uses one charge (`S/419_Pokevial.rb:84-105`). It has no battle handler, so it works only outside battle | Read from the scripts; the field use seen in game through the pause menu's hotkey, a heal and an empty Pokévial ([Menus → Pause Menu](menus.md#pause-menu)) |
| Permafainted Pokémon | `heal_party` calls `heal` on each member, and the challenge's `heal_HP` returns early for a permafainted Pokémon (`P/Challenge Modes/004_Permafaint.rb:16-20`), so it stays at 0 HP, as after a whiteout ([Nuzlocke](nuzlocke.md)) | Read from the scripts; the same path as the Whiteout row of Nuzlocke |
| Charges | Starts at 1 (`INITIAL_CHARGES_POKEVIAL`). Each of the four "Mejora del Pokévial" (Pokévial upgrade) pickups, on Ruta 20 (map 16, event 40), in Ciudad Azulona (76, 37), on Islas Espuma (134, 22) and on Ruta 24 (155, 10), runs `add_new_vial_charge`, raising the maximum and the current charges by 1, to 5 in all | Read from the scripts and the map data |
| Recharge | Every nurse runs common event 13, "Enfermera Joy", whose `recharge_vial` refills it to the maximum; all 16 Pokémon Centers, the League lobby and the Battle Tower have one | Scan of the map data |
