## RGSS Table

A `Table` is marshalled as a user-defined dump: five little-endian 32-bit integers (dimensions, x size, y size, z size, element count) followed by the elements as little-endian signed 16-bit integers, x fastest, then y, then z. Element `(x, y, z)` is at index `x + xsize × (y + ysize × z)`. Map tiles are three layers (z 0 to 2).

## Movement

Verified 2026-10-02 on `es-v4.14` with Python scripts on `harness.drive` that held a direction for one tick at a time at the `1x` preset and read `System.uptime`, the player's position, `real_x`/`real_y`, `moving?`, `jumping?` and `move_speed` after each tick, and with `wonder go`, in the sessions under [Event Pages](#event-pages). Times are in ticks at `1x`, where a tick is 0.025 s of game time ([Runtime → Speed](runtime.md#speed)). Movement is timed by `System.uptime`, so at another preset a move takes the same game time in fewer ticks: at `max` (0.2 s a tick) a walking step and a running step each take one tick.
