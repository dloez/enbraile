# State Reference

Where the game keeps the state the harness reads, and how it is laid out, verified on the build we play with our own tooling. The bridge's `read` request that fetches it is described in [Runtime → State Read](runtime.md#state-read); the harness models are `src/anil/harness/state.py` (`anil state`). Its facts were verified with Wonder's harness and are kept as recorded there; [Runtime](runtime.md) maps Wonder's commands, modules and paths to `anil`'s.

Verified 2026-10-02 on `es-v4.14` with `wonder state` and `wonder state --json` against `wonder eval` of the same objects through the game's own methods, in sessions `20261002-024226`, `20261002-024627` and `20261002-024934`. The game started from the snapshot `anil-c` (a new game in the player's bedroom, map 28). An eval emptied the party, set variable 55 to 2 and moved the player to the laboratory (map 29) at (17, 12), facing up. The driver then pressed `C` on the middle Poké Ball (event 29). The game's own event ran: Oak's question, the yes/no choice, `pbAddPokemon` and the nickname entry, where the driver typed `Chispa`. That gave a level 5 Charmander, saved as the snapshot `anil-starter`. Items, a held item and a boxed Pokémon were then given by eval (`$bag.add`, `item =`, `$PokemonStorage[1, 0] =`), and a wild battle was started by an eval-run `WildBattle.start(:PIDGEY, 3)` and fought with `C`. No screen was compared; the values are the game's own methods as `wonder eval` answered them.

## Bag

`$bag@pockets` is a list indexed by pocket. Index 0 is an empty, unused list, and 1–8 hold `[item Symbol, quantity]` pairs. `PokemonBag.pocket_names` lists the eight names from index 0, so pocket *n* is named by entry *n* − 1: Objetos, Medicinas, Poké Balls, MTs & MOs, Bayas, Mega Piedras, Obj. Batalla, Obj. Clave. A new game's bag after the starter is empty. Potion ×3 given by `$bag.add` read in pocket 2 (Medicinas) and Oran Berry ×2 in pocket 5 (Bayas), as `$bag.pockets` showed.
