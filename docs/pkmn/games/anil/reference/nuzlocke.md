# Nuzlocke

How Añil's Challenge Modes plugin enforces the Randomlocke's Nuzlocke rules, as seen in the running game. The configured rules are in [Randomlocke Design → Nuzlocke](../explanation/randomlocke-design.md#nuzlocke); what the competition makes of them is in [Rules](../../../series/1/reference/rules.md). Its facts were verified with Wonder's harness and are kept as recorded there; [Runtime](runtime.md) maps Wonder's commands, modules and paths to `anil`'s.

Verified 2026-10-02 on `es-v4.14` with the Randomlocke mod and the bridge, by `wonder check nuzlocke` (`packages/harness/src/harness/check.py`), in sessions `20261002-084401` (save `nz-9`) and `20261002-084419` (save `nz-10`, inside `wonder check all`). ## Eggs

The 16 eggs the Randomlocke mod gives every new game ([Randomlocke Design → Eggs](../explanation/randomlocke-design.md#eggs)), as the game handles them under the challenge. Verified 2026-10-02 on `es-v4.14` with the mod and the bridge, by `wonder check eggs egg-hatch` (`packages/harness/src/harness/check.py`) in session `20261002-184953` (save `egg-new-4`). That was a new game started by `wonder run --hidden` on an empty save and driven from the title through the intro to the bedroom. The session ran the two checks alone, then `wonder check all`, which passed all 50 checks. `replay` replayed it as `20261002-185308` with no digest mismatch over ticks 39–6,928 (2,758 advances, 722 evals, 27 restores). An earlier session of the same build less the damaging-move step, `20261002-183631` (save `egg-new-3`), saw the same apart from the moves and also passed all 50.
