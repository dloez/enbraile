# Battle Mechanics

Which generation's battle rules Añil plays by, as seen in the running game with the Randomlocke mod: the type chart, the typings, the status conditions, critical hits and weather, the damage formula, accuracy, the critical hit's chance, turn order and a move's targets, and what the end of a round takes and gives. Species, moves and abilities are held to Gen 1–5 ([Rules → Gen 1–5 Limits](../../../series/1/reference/rules.md#gen-15-limits)); the mechanics are not. How players read these facts is in [Rules → Battles Use Modern Rules](../../../series/1/reference/rules.md#battles-use-modern-rules). Its facts were verified with Wonder's harness and are kept as recorded there; [Runtime](runtime.md) maps Wonder's commands, modules and paths to `anil`'s.

Verified 2026-10-02 on `es-v4.14` with the Randomlocke mod and the bridge, by `wonder check battle-mechanics` (`packages/harness/src/harness/check.py`). It passed twice in session `20261002-133828` (save `bmech-dev`), booted into the snapshot `lvcap2-new` (the bedroom after the intro, 0 badges), the first time in an earlier version without the full type chart, the type list and the retyped species, and once in session `20261002-134009` (save `bmech-new-1`), a new game started by `wonder run --hidden` on an empty save and driven from the title through the intro to the bedroom.
