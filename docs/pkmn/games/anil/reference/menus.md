# Menus Reference

The pause menu, party, bag, PC storage, Poké Mart, full-party store question, move relearner, save and prompt-chain screens, and the battle's command and fight menus: what each shows, how its cursor moves and what it asks, as the menu layer and the battle layer drive them ([Menu Design](../explanation/menu-design.md), [Battle Layer Design](../explanation/battle-layer-design.md)). The bridge payloads and context lines that read them are in [Runtime → Context](runtime.md#context). Its facts were verified with Wonder's harness and are kept as recorded there; [Runtime](runtime.md) maps Wonder's commands, modules and paths to `anil`'s.

Verified 2026-10-02 on `es-v4.14` by opening each screen by real input and reading `wonder state` (and the same classification from a Python script on `harness.drive`) in sessions `20261002-222011` and `20261002-222958`. Both were booted into the snapshot `busy-anil` (Pueblo Paleta, a party of the level 5 Charmander "Chispa"). An eval added a Pikachu and an Eevee, three each of Potion, Rare Candy, Fire Stone, TM01, Poké Ball and Oran Berry, a Rattata in box 0 and a Pidgey in box 1, and set Chispa's HP to 5. Eval-set interpreters ran `pbPokemonMart([:POKEBALL, :POTION, :ESCAPEROPE])`, `pbPokeCenterPC`, `pbLearnMove` with Lanzallamas on a Chispa knowing four moves, `pbAddPokemon` gifts, and an evolution scene from Squirtle to Wartortle. Lists the game builds per Pokémon, item or game state are given as seen, with the rule from source where one was read. Rows marked "source" were read from the cited script and not exercised.
