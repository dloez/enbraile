# Randomizer

What Añil's randomizer plugin ("Random Pokemon & Moves + Randomizer EX (Abilities)") does in the running game, with the Randomlocke's configuration. The configured options are in [Randomlocke Design → Randomizer](../explanation/randomlocke-design.md#randomizer). The new-game `randomizer` check, which reads those options, is in [Runtime → Checks](runtime.md#checks). Its facts were verified with Wonder's harness and are kept as recorded there; [Runtime](runtime.md) maps Wonder's commands, modules and paths to `anil`'s.

Verified 2026-10-02 on `es-v4.14` with the Randomlocke mod and the bridge, by `wonder check random` (`packages/harness/src/harness/check.py`), in session `20261002-093928` (save `rnd-chk-3`). It booted into the snapshot `check-20261002-082736-949`, a new game in the bedroom with 0 badges, and ran the nine `random-*` checks in order; each row names the check that saw it. The same checks passed inside `wonder check all` in session `20261002-094009` ([Runtime → Checks](runtime.md#checks)). Rows marked `wonder eval` come from session `20261002-092759`, booted into the same snapshot, except the `rand` row, from session `20261002-093643`, also booted into it. Badge counts other than 0 were set by eval for the draw and put back afterwards.

These sessions predate the mod's Gen 1–5 caps (rows citing later sessions say so), so the rows on species let in, starters, moves from every generation and the ability table describe the plugin uncapped. What the caps change is in [Runtime → Randomlocke Mod](runtime.md#randomlocke-mod).

## Read from Code

Read from the plugin's code (`P/Random Pokemon & Moves + Randomizer EX (Abilities)/`) on 2026-10-02 and not yet seen in game:

- **No seed:** draws come from the Kernel RNG through `sample`, `shuffle` and `rand`, so each new game is randomized on its own.
- **Egg and tutor moves are not randomized.**
- **`valid_random_species` keeps its last draw after 1,000 failed tries** (`001_Main.rb:355-369`), unvalidated. Each try draws through the top-level `random_species`, which the mod replaces with a draw from its allow-list, so under the mod that last draw is still an allowed species ([Randomlocke Design → Applying the Caps](../explanation/randomlocke-design.md#applying-the-caps)).
- **`TRAINERS_CAN_GIVE_RANDOM_ITEMS` never fires:** its test uses integer division (`003_Items.rb:121`).
